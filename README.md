# مغامرات السعودية | Saudi Adventures

لعبة منصات ثنائية الأبعاد بأسلوب Pixel Art، تعمل من المتصفح مباشرة (HTML + CSS + JavaScript + Phaser 3.80.1).
لا تحتاج خادمًا ولا قاعدة بيانات، وكل الرسومات والأصوات مولّدة بالكود (لا توجد ملفات صور أو صوت).

## هيكل المشروع

```
saudi-adventures/
├── index.html              الصفحة الرئيسية (الواجهة + تحميل Phaser والسكربتات)
├── .nojekyll               يمنع GitHub Pages من معالجة الملفات
├── css/style.css           تنسيق الواجهة (الشاشات، العدادات، أزرار اللمس)
└── js/
    ├── config.js           أرقام الإحساس باللعب (السرعة، القفز، القلوب...)
    ├── level1.js           بيانات المرحلة (الأرض، الحفر، العملات، الأعداء...)
    ├── art.js              الرسومات Pixel Art (الشخصيات، البلاطات، الخلفيات، الرايات)
    ├── audio.js            المؤثرات الصوتية + الكتم
    ├── input.js            لوحة المفاتيح وأزرار اللمس
    ├── leaderboard.js      النقاط ولوحة الأبطال (على الجهاز أو Supabase)
    ├── ui.js               الشاشات والعدادات واختيار الشخصية
    ├── scenes/BootScene.js توليد الرسومات
    ├── scenes/GameScene.js منطق اللعب والفيزياء والتصادمات
    └── main.js             تشغيل اللعبة وإدارة الحالات (قائمة/لعب/إيقاف/نتيجة)
```

كل المسارات نسبية (`css/...` و `js/...`)، لذلك تعمل كما هي على GitHub Pages وNetlify، حتى لو كان الموقع داخل مجلد فرعي مثل `username.github.io/saudi-adventures/`.

## التشغيل محليًا

**الطريقة الأسهل:** افتحي ملف `index.html` بالنقر المزدوج. اللعبة تعمل بدون خادم لأنها لا تحمّل ملفات صور.
(تحتاج اتصال إنترنت لأن مكتبة Phaser والخطوط تُحمّل من CDN.)

**بخادم محلي (أدق لمحاكاة النشر):**
- إذا عندك Python: افتحي الطرفية داخل المجلد واكتبي `python -m http.server 8000` ثم افتحي `http://localhost:8000`
- أو في VS Code: إضافة **Live Server** ← زر Go Live.

## النشر على Netlify (الأسرع، بدون حساب GitHub)

1. ادخلي https://app.netlify.com/drop وسجّلي دخول (حساب مجاني).
2. اسحبي **مجلد** `saudi-adventures` كاملًا (المجلد الذي فيه `index.html` مباشرة) وأفلتيه في الصفحة.
3. خلال ثوانٍ يعطيك رابطًا مثل `https://random-name.netlify.app`.
4. لتغيير الاسم: Site configuration ← Change site name.
5. للتحديث لاحقًا: Deploys ← اسحبي المجلد الجديد مرة ثانية.

## النشر على GitHub Pages

1. أنشئي مستودعًا جديدًا على GitHub (Public) باسم مثل `saudi-adventures`.
2. اضغطي **uploading an existing file** وارفعي **محتويات** المجلد (index.html و css و js و .nojekyll) بحيث يكون `index.html` في جذر المستودع، وليس داخل مجلد فرعي. ثم Commit changes.
   - ملاحظة: ملف `.nojekyll` مخفي في بعض الأنظمة. إذا لم يظهر لك، اضغطي Add file ← Create new file وسمّيه `.nojekyll` واتركيه فارغًا.
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` ومجلد `/ (root)` ← Save.
4. انتظري دقيقة أو اثنتين، ثم يظهر الرابط: `https://اسم-المستخدم.github.io/saudi-adventures/`

**بعد أي تعديل ورفع ملفات جديدة:** غيّري رقم الإصدار `?v=2` في `index.html` (مثلًا إلى `?v=3`) في كل روابط `css` و`js`، حتى تحمّل المتصفحات النسخة الجديدة فورًا بدل النسخة المحفوظة عندها.

## التحكم

| الكمبيوتر | الجوال |
|---|---|
| الأسهم أو A / D للمشي | زرّا الأسهم أسفل يسار الشاشة (ضغط مستمر) |
| Space (أو ↑ أو W) للقفز — الضغط المطوّل يقفز أعلى | زر «قفز» أسفل يمين الشاشة |
| Esc أو P للإيقاف المؤقت | زر الإيقاف أعلى الشاشة |
| Enter لتأكيد الزر الأساسي في الشاشات | — |

### كيف تعمل أزرار اللمس
- مبنية على Pointer Events، وكل إصبع يُتابَع وحده: تقدرين تمشين وتقفزين في نفس الوقت.
- رفع الإصبع، أو خروجه من الزر، أو انقطاع اللمس (مكالمة/إشعار) يوقف الحركة فورًا.
- سحب الإصبع من سهم لآخر يغيّر الاتجاه بدون رفعه.
- الضغط المستمر على «قفز» = قفزة واحدة فقط.
- الأزرار تغذي نفس نظام لوحة المفاتيح (`js/input.js`)، فلا يوجد نظام حركة منفصل.
- تظهر تلقائيًا على الجوال والتابلت، وتظهر عند أول لمسة على أي جهاز بشاشة لمس، وتختفي إذا استُخدمت لوحة مفاتيح حقيقية.
- في وضع اللمس تنزل الكاميرا قليلًا (`SA.TOUCH_VIEW_EXTRA` في `js/config.js`) حتى يبقى سطح الأرض والأعداء فوق الأزرار.
- تمرير الصفحة ممنوع أثناء اللعب فقط؛ القوائم تبقى قابلة للتمرير.

### تجربة اللمس على الجوال
1. انشري اللعبة (Netlify أو GitHub Pages) وافتحي الرابط من الجوال، أو شغّلي خادمًا محليًا وافتحي `http://عنوان-جهازك:8000` من جوال على نفس شبكة الواي فاي.
2. أدِيري الجوال بالعرض واضغطي «ابدأ اللعب».
3. جرّبي: ضغط مستمر على السهم، المشي مع القفز معًا، سحب الإصبع خارج الزر، والقفز بالضغط المطوّل.
4. على الكمبيوتر بدون جوال: Chrome ← أدوات المطور (F12) ← أيقونة الجوال (Toggle device toolbar) ← اختاري جهازًا ثم حدّثي الصفحة.

## نظام اللعب

- اختيار الشخصية في شاشة البداية: **مطلق** (ثوب وشماغ) أو **نورة** (عباية وحجاب). الاختيار يُحفظ في المتصفح.
- 3 قلوب. خسارة قلب عند: السقوط في حفرة، لمس الأشواك، أو لمس العقرب من الجانب.
- القفز فوق العقرب يهزمه.
- التمرة تضيف قلبًا (حتى 5).
- راية خضراء في منتصف المرحلة = نقطة حفظ: بعد خسارة قلب تكمل منها.
- إذا انتهت القلوب: شاشة «انتهت المحاولات» وزر يرجعك لبداية المرحلة بقلوب كاملة.
- بوابة القرية في النهاية = الفوز، مع عدد العملات والوقت ونجوم (3 نجوم = كل العملات).

## لوحة الأبطال (أفضل 10)

يكتب اللاعب اسمه في شاشة البداية (لا تبدأ اللعبة بدون اسم)، وبعد الفوز أو انتهاء المحاولات تُحفظ نتيجته تلقائيًا ويظهر ترتيبه.
كل اسم يظهر في اللوحة مرة واحدة بأفضل نتيجة له. اللوحة تُفتح من زر «لوحة الأبطال» في الشاشة الرئيسية أو شاشة النتيجة.

**حساب النقاط** (في `js/leaderboard.js`):
- كل عملة = 10
- الوصول لبوابة القرية = 500
- كل قلب متبقٍ عند الفوز = 100
- مكافأة السرعة عند الفوز = 5 نقاط لكل ثانية تحت 3 دقائق
- عند التعادل يتقدم الأسرع.

**بدون إعداد:** النتائج تُحفظ على جهاز كل لاعب فقط.

**لوحة واحدة لكل اللاعبين (Supabase مجاني):**
1. سجّلي في https://supabase.com وأنشئي مشروعًا جديدًا (New project).
2. افتحي **SQL Editor** والصقي هذا ثم Run:

```sql
create table public.scores (
  id bigint generated always as identity primary key,
  name text not null check (char_length(name) between 1 and 16),
  score int not null check (score between 0 and 3000),
  coins int not null check (coins between 0 and 200),
  time_sec int not null check (time_sec between 1 and 7200),
  character text not null check (character in ('boy', 'girl')),
  win boolean not null default false,
  created_at timestamptz not null default now()
);
alter table public.scores enable row level security;
create policy "anyone can read scores" on public.scores for select using (true);
create policy "anyone can add a score" on public.scores for insert with check (true);
```

3. من **Project Settings ← API** انسخي **Project URL** و **anon public key**.
4. الصقيهما في `js/config.js` داخل `SA.LEADERBOARD`، ثم ارفعي الملف المعدّل.
5. لحذف اسم غير مناسب: Supabase ← **Table Editor** ← `scores` ← احذفي الصف. (اللاعبون يقدرون يضيفون فقط، ولا يقدرون يعدّلون أو يحذفون.)

ملاحظة صريحة: أي لوحة نتائج تُرسل من المتصفح يمكن لشخص خبير تزويرها بإرسال نتيجة مباشرة. الحدود في الجدول تمنع الأرقام المستحيلة، لكنها لا تمنع التلاعب تمامًا. هذا مقبول للعبة ممتعة، وغير مناسب لمسابقة بجوائز.

## التعديل والتطوير

- **صعوبة اللعب:** `js/config.js` (سرعة المشي، قوة القفز، عدد القلوب، سرعة العقارب).
- **تصميم المرحلة:** `js/level1.js` — كل شيء بالأعمدة والصفوف، مع شرح في أعلى الملف.
- **الألوان والشخصيات:** `js/art.js` — كل شخصية مرسومة كشبكة حروف، وكل حرف لون في `PAL`.
- **استبدال الرسومات بصور احترافية:** ضعي ملفات PNG في مجلد `assets/` وحمّليها في `BootScene.preload` بنفس المفتاح
  (مثل `this.load.image('t_sand', 'assets/sand.png')`)، والدالة تتخطى توليد أي رسمة موجودة مسبقًا.
  قائمة المفاتيح موجودة في `SA.Art.KEYS` داخل `art.js`.
  مقاسات الحالية: الشخصية 32×42، البلاطة 32×32، العملة 24×24، العقرب 36×20.
